Hoe het scannen werkt, zonder JavaScript

  1. Het scanveld is het enige tekstveld in een formulier zonder knop. De scanner typt de code als een toetsenbord en geeft zelf de Enter, en die verstuurt het formulier.
  2. De codes die al gescand zijn, gaan mee als verborgen velden. De controller bouwt bij elke scan de hele order opnieuw op.
  3. Na elke scan maakt de controller het scanveld weer leeg, anders zet de pagina de vorige code terug.
  4. Een onbekende code is geen bouwconflict. Die melding komt bij het scanveld.

De kleur is een beslissing van het scherm

Elke regel draagt een ernst: in orde, opmerking of niet in orde. Pas de view maakt daar een kleur van. Zo blijft de afspraak uit het ontwerp overeind: de API en de controle geven nooit een kleur terug.
